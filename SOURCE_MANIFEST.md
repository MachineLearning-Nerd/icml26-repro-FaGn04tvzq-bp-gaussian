# Source manifest

This file fixes the paper, data, code, and environment boundaries for the
reproduction audit. It is deliberately explicit about substitutions.

## Paper record

- Title: *Belief Propagation Converges to Gaussian Distributions in
  Sparsely-Connected Factor Graphs*
- Authors: Tom Yates, Yuzhou Cheng, Ignacio Alzugaray, Danyal Akarca, Pedro A.
  M. Mediano, and Andrew J. Davison
- arXiv: [2601.21935](https://arxiv.org/abs/2601.21935), version 1
- Review identifier: [FaGn04tvzq](https://openreview.net/forum?id=FaGn04tvzq)
- arXiv status at audit time: preprint under review
- Metadata checked: 2026-08-14

The source anchors used by the audit are the paper's topology experiments
(Figure 4a–c), the Appendix-D exclusion-boundary derivation, the Appendix-I
synthetic settings, and the stereo/textureless-versus-edge experiment
described around Figure 5 and the supplementary material.

## Data boundary

- C1–C5 use synthetic probability vectors, graph topologies, and random seeds
  generated by the committed NumPy implementation.
- C6 uses the official Middlebury Cones stereo pair. The registered run
  resized the 375×450 scene to 150×200 and scaled the horizontal disparity
  labels accordingly.
- The dataset is not redistributed in this repository. Reproduction must
  obtain it through the authorized Middlebury source and preserve the
  preprocessing described in repro/src/stereo_cones.py.

## Code and evidence boundary

- Synthetic producer: repro/src/paper_scale.py
- Stereo producer: repro/src/stereo_cones.py
- End-to-end verifier: repro/src/verify_bp.py
- Figure producer: reports/bp-gaussian/make_figures.py
- Reader-facing tutorial: notebooks/bp_gaussian_tutorial.py
- Recorded verdict: outputs/verdict.json

The registered experiment was produced from the historical source snapshot
43ee5c73417181e0faf29be9223745d06e0af19a on the old
orx/map-decoded-cones-comparison ref. The ref is retained here as provenance
only; the normalized public branch is release/map-decoded-cones.

## Environment boundary

The recorded run used:

- Hugging Face cpu-upgrade
- Python 3
- NumPy 2.3.2
- 101 synthetic seeds for the topology and exclusion checks
- 31 paired seeds for the degree check
- five seeds for the Cones comparison
- 1,024 probability bins for the paper-scale synthetic checks

The exact command is recorded in README.md and
.trackio/logbook/pages/verification-run/page.md.

## Reproduction limitations

The authors' supplementary factor implementation was unavailable to this
audit. GBP, the photometric factors, the resizing convention, and the
posterior decoder are therefore clean-room choices. The audit reports these
choices and does not present them as source-exact.
